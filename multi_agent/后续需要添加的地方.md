六、Harness 注册配置是什么？
注册配置 = 组件运行元数据，注册时一次性配置，包含两大类：
参数类：input_schema（入参规范）
运行管控类：timeout、retry_times、exception_ignore_list（哪些异常不重试）、最大内存限制
修改配置不用改 Skill 源码，重新注册 / 动态更新配置即可全局生效。
七、运行快照 Snapshot：配置、存储原理、多场景用途
1. 快照包含内容（一次调用全量现场）
trace_id + 原始入参input + runtime上下文 + 各依赖返回数据快照 + 环境变量 + 执行耗时 + 异常堆栈
区别日志：日志是零散文本，快照是结构化全量运行现场。
2. 如何开启 & 设置快照
注册或全局开启：
python
运行
# 全局配置harness开启快照
harness.set_global_option(snapshot_enable=True, snapshot_store="sqlite") # 存储到本地库/redis
# 单个组件单独关闭快照
harness.register_skill(name="xxx", snapshot_enable=False)
Harness 在每次 run 执行结束后自动落地快照到存储，生成唯一snap_id。
